## 两个页面内对照

入口位于现有房间的「播放诊断 → 当前页面对照模式」，默认正常同步，刷新或换房恢复默认，不写服务器配置、URL 开关或本地持久偏好。

1. **A：原生播放**：保留同一个受保护的媒体地址，通过现有已登录房间请求媒体；开启浏览器原生 controls，不运行 VOD 同步控制器，不跟随 Host 播放/暂停/跳转。需要用户主动点击播放。原有会话、观影权限、签名重定向与 Range 鉴权不变，不复制或泄露令牌。
2. **B：固定 1×，仅跟随 Host 指令**：初次对齐后保留明确 Host seek/play/pause；忽略速度变化，关闭自动调速、漂移定位、补偿 seek 和暂停帧静音解码恢复。保留命令版本、未来时间锚点和超时状态。这个模式有意允许漂移，不能据此宣布同步合格；Host 测试时也保持 1×。

切换会暂停本机并要求重新启用播放，不改变其他人的模式。对照模式不上报用于自动切集的进度，原生模式也不报告「已同步」。诊断显示实际 muted、volume、playbackRate；这些属性只能证明播放器状态，不能证明用户听到了声音。
